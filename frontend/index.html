Tài Liệu
REST API

Tích hợp hệ thống nhận diện âm nhạc vào ứng dụng của bạn qua chuẩn RESTful JSON API. Hoàn toàn stateless và dễ sử dụng.

🚀 Swagger UI – Giao Diện API Tương Tác

Thử nghiệm trực tiếp tất cả endpoints, xem request/response schema và tài liệu đầy đủ.

Mở Swagger UI ↗
POST /api/predict

Upload file âm thanh (multipart/form-data). Trả về thể loại, xác suất phân bố và 60 đặc trưng âm học.

curl -X POST "http://localhost:8000/api/predict" \
  -H "accept: application/json" \
  -F "file=@my_song.mp3"
POST /api/predict-demo

Phân tích bài hát mẫu có sẵn. Query params: genre và filename.

curl -X POST \
  "http://localhost:8000/api/predict-demo\
?genre=blues&filename=blues_1.wav"
GET /api/genres

Danh sách 10 thể loại nhạc kèm mô tả chi tiết, icon, màu sắc và nghệ sĩ tiêu biểu.

curl "http://localhost:8000/api/genres"
GET /api/demo-samples

Danh sách tất cả file nhạc mẫu trong thư mục music_test/.

curl "http://localhost:8000/api/demo-samples"
GET /api/history

Lịch sử phân tích từ SQLite. Query param: limit (1-200, mặc định 50).

curl "http://localhost:8000/api/history?limit=20"
GET /api/stats

Thống kê tổng hợp: tổng lượt, độ tin cậy trung bình, phân bố thể loại.

curl "http://localhost:8000/api/stats"
DELETE /api/history/{id}

Xóa một bản ghi lịch sử theo ID.

curl -X DELETE \
  "http://localhost:8000/api/history/5"
GET /api/health

Kiểm tra trạng thái server và thông tin model AI đã tải.

curl "http://localhost:8000/api/health"
